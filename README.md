# Simple Interactive Compass Dial
This project is a simple interactive compass dial built using HTML, CSS, and JavaScript. The compass dial allows users
to rotate it by dragging the mouse, or clicking on a sector on the dial. 
This provides an engaging way to input a degree direction, with the dial visually indicating the current orientation. 

The compass dial is designed to be responsive and user-friendly, making it easy for users to interact with it 
in various applications. A numeric input field is also included, allowing users to enter a specific degree value 
directly, which will update the dial accordingly. The field also indicates the degree position of the dial after the 
user interacts with it, providing real-time feedback on the current orientation.

The main features of this compass dial include:
- Interactive rotation: Users can click or drag the needle to rotate it, 
  - Or input a specific degree value in the input field to set the dial's orientation.
- Real-time feedback: The current degree position is displayed in the input field, updating as the user interacts with the dial.
- Responsive design: The compass dial is designed to work well on various screen sizes and devices, ensuring a consistent user experience across platforms.
